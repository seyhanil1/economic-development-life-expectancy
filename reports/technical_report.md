# Technical Report

## Pipeline

```
download_data.py ──► data/raw/*.json  (+ download_manifest.json)
clean_data.py    ──► data/processed/*.csv, cleaning_log.json
statistical_analysis.py ──► reports/tables/*.csv, results.json
make_figures.py  ──► figures/*.png
run_pipeline.py  = all four in order (--offline skips the download)
notebooks/01_analysis.ipynb = the same functions, run interactively
```

Every number in the reports can be traced to a file in `reports/tables/`. Every table is generated by code. Nothing is typed in by hand.

## download_data.py

* Endpoint: `https://api.worldbank.org/v2/country/all/indicator/{code}?format=json&date=2000:2025&per_page=1000`.
* **Pagination:** reads `pages` from page 1 and requests pages 1..`pages`. It fails if the page count changes during the download, and it checks that `len(records) == total`.
* **Errors:** connection errors, time-outs, HTTP 429/5xx and bodies that are not valid JSON are retried up to 5 times with exponential back-off (1, 2, 4, 8 s). Other 4xx responses fail at once. The API's in-band error format (`[{"message": [...]}]` with HTTP 200) is detected and raised as `WorldBankAPIError`. An unexpected JSON structure also raises.
* The country list and the indicator metadata (`/v2/sources/2/series/{code}/metadata`) are saved alongside the data. Licence, unit and definition are recorded from the API, not typed in by hand.
* Provenance: a manifest with the UTC retrieval timestamp, request URLs, record counts, the API `lastupdated` stamp and SHA-256 checksums.

## clean_data.py

* Records are flattened to (iso3, iso2, name, year, value). `null` becomes NaN, never 0.
* Blank ISO3 codes are resolved through the 2-letter API id. An unknown code raises `DataIntegrityError`.
* Duplicates: identical repeated (iso3, year, value) rows are dropped and counted. Conflicting duplicates raise.
* Aggregates are removed with the country list (`region == "Aggregates"`), not with a hand-written list of codes.
* The two indicators are outer-merged with `validate="one_to_one"`. The result is placed on the full economy × year grid, so that economies with no records at all still appear as missing.
* Flags and an `exclusion_reason` are added. The log of GDP is computed only for GDP > 0.

## statistical_analysis.py

* `correlations`: SciPy `pearsonr` and `spearmanr`, with Fisher-z confidence intervals.
* `fit_models`: statsmodels formula OLS with `cov_type="HC3"`. All models share one data frame, so they use the same sample.
* `diagnostics`: `het_breuschpagan`, `het_white`, `jarque_bera`, `shapiro`, `linear_reset`, and `OLSInfluence` (Cook's distance, hat values, studentised residuals, DFBETAS).
* `panel_models`: dummy-variable fixed effects through `C(iso3)` and `C(year)`, with `cov_type="cluster"` grouped by country. With ~199 clusters, the cluster-robust variance estimator is reliable.
* `slope_trend_test`: an ln GDP × trend interaction with year FE and clustered standard errors.
* `long_differences`: a cross-section of changes with HC3 standard errors.

## Reproducing the results

```bash
pip install -r requirements.txt
python src/run_pipeline.py --offline   # exact results, from the saved raw data
python src/run_pipeline.py             # fresh download; may differ after WDI revisions
pytest
```

## Audit

`audit/run_audit.py` checks the pipeline without changing it. It reads the archived WDI releases 202503 and 202504 from `data/raw/archive/*.json.gz` through `audit/archive_io.py`, which checks each decompressed file against the SHA-256 of the original download recorded in `ARCHIVE_MANIFEST.json`. `--refetch` re-downloads both releases and compares them with the stored originals, without overwriting them. The audit writes its results to `reports/audit/`. It covers:

* data releases, with a revision analysis of the Central African Republic series;
* classification of aggregates and territories, and the lists of economies;
* the missing-data arithmetic;
* HC3 and clustered SEs computed by hand;
* the FE design matrix and an FWL re-estimate;
* the slope-trend p-value;
* an independent NumPy recomputation and a 5-country example that can be checked by hand;
* sensitivity analyses.

The findings are in `reports/final_scientific_audit_tr.md`.

## Known technical limitations

* The figure scripts use Matplotlib's default fonts. The appearance may differ slightly between platforms.
* Results were produced on Python 3.14 / pandas 3.1. Older versions were not tested.
* The executed notebook stores its images inline (~1.4 MB). You can clear the outputs before committing if you want a smaller diff.
* There is no CI configuration (for example GitHub Actions) yet.
